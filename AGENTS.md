## salonbook — Next.js 16 App Router app (single package)

### Commands
- `npm install` — install dependencies (lockfile: `package-lock.json`)
- `npm run dev` — dev server on http://localhost:3000 (Turbopack)
- `npm run build` — production build (includes typechecking)
- `npm run start` — production server (run `build` first)
- `npm run lint` — ESLint (Next.js Core Web Vitals + TypeScript rules)

There is no `test` or `typecheck` script and no test suite configured; typechecking happens as part of `next build`.

### Entry points & structure
- `src/app/layout.tsx` — root layout, metadata, Geist fonts (`next/font/google`)
- `src/app/page.tsx` — home page
- `src/app/globals.css` — Tailwind CSS 4 (`@import "tailwindcss"`), `@theme inline` theme vars, `dark` custom variant; no `tailwind.config.js`
- `src/components/ui/` — shadcn/ui components built on `@base-ui/react` primitives (e.g. `button.tsx`)
- `src/lib/utils.ts` — `cn()` re-exported from the `cn` package
- Path alias `@/*` → `./src/*`; shadcn aliases in `components.json` (`@/components`, `@/components/ui`, `@/lib`, `@/lib/utils`, `@/hooks`)

### Gotchas
- `next-env.d.ts` imports generated `.next/dev/types/*.d.ts` — do not edit; `.next/` is gitignored and regenerated by `next dev`.
- `next.config.ts` sets `cacheComponents: true`, `partialPrefetching: true`, and a Turbopack CSS loader (`@tailwindcss/turbopack`).
- `.env*` files are gitignored; no environment variables are configured.
- No CI workflows, no pre-commit hooks, and no formatter (Prettier) config.
- UI component convention: merge classes with `cn()`, define variants with `class-variance-authority`, place new UI components in `src/components/ui/`.

### Verify before finishing
`npm run lint` and `npm run build` both pass.
